# Contributing

Read [CLAUDE.md](CLAUDE.md) first. One milestone per `m<N>-<slug>` branch and PR.
Use small Conventional Commits; do not merge before lint, types, tests and CI pass.
Keep tests offline. Do not commit secrets, real biometric data, or benchmark estimates.
Run `python scripts/tasks.py lint`, `typecheck`, and `test` before submitting a PR.
