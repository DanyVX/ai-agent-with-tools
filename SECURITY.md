# Security

This repository is a research/portfolio implementation and is not approved for
production, biometric processing, or unattended side effects.

Do not file exploit details or secrets in public issues. Contact the repository
owner privately to coordinate disclosure. Remove and rotate exposed credentials
immediately. Deleting a committed credential is not sufficient.

No live network adapters or tool invocation functionality exists in M0. Later
milestones must maintain explicit trust boundaries, sandbox confinement and
deny-by-default approvals.
